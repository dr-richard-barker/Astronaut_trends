# Data Dictionary

All processed datasets are UTF-8 CSV with a header row, generated by
`scripts/build_dataset.py` from the Planet4589 catalogues in `data/raw/`.

Duration bins (ordered): `less than 1 hour` < `1 hour to 1 week` < `1 week to 50 days`
< `50 days to 1 year` < `more than 1 year`. These are based on an astronaut's
**cumulative career** time in space, not a single mission.

Citizenship groups: `USA` (US), `Russia` (RU, incl. USSR), `China` (CN), `Other`
(all other nationalities). Derived from the catalogue's citizenship code.

---

## `data/raw/astro.html`, `data/raw/missions.html`
Verbatim fixed-width snapshots of the Planet4589 source lists, kept so the exact
inputs behind a release are archived. Re-downloaded by the pipeline unless
`--offline` is passed. See <https://planet4589.org/space/astro/lists/>.

## `data/processed/astronaut_level.csv`
One row per flown astronaut (the tidy base table).

| Column | Type | Description |
|---|---|---|
| `Name` | string | Astronaut name (from the catalogue). |
| `Citizen` | string | Raw citizenship code (e.g. `US`, `RU`, `CN`, `F`, `J`). |
| `CitizenGroup` | string | Cleaned group: USA / Russia / China / Other. |
| `Gender` | string | Male / Female / Unknown (from the catalogue's `G` field). |
| `BornYear` | int | Year of birth, if recorded. |
| `FirstMissionYear` | int | Launch year of the astronaut's earliest mission. |
| `LastMissionYear` | int | Launch year of the astronaut's latest mission. |
| `CareerSpanYears` | int | `LastMissionYear − FirstMissionYear`. |
| `NumMissions` | int | Number of mission tags parsed for the astronaut. |
| `DurationSeconds` | int | Cumulative career time in space, in seconds. |
| `DurationDays` | float | Cumulative career time in space, in days. |
| `DurationBin` | string | One of the five ordered duration bands. |

## `data/processed/astronaut_summary.csv`
The headline aggregate (schema-compatible with the original 2024 file, plus two
extra years of data). One row per year × country × duration band.

| Column | Type | Description |
|---|---|---|
| `FirstMissionYear` | int | Year of first spaceflight. |
| `CitizenCleaned` | string | Citizenship group. |
| `DurationBinned` | string | Duration band. |
| `Count` | int | Number of astronauts in that cell. |

## `data/processed/country_by_bin.csv`
Astronaut counts by citizenship group × duration band (all years). Feeds the
sankey, radar, and composition charts.

| Column | Type | Description |
|---|---|---|
| `CitizenGroup` | string | Citizenship group. |
| `DurationBin` | string | Duration band. |
| `Count` | int | Number of astronauts. |

## `data/processed/decade_by_country.csv`
Astronaut debut counts by decade × citizenship group. Feeds the chord and network charts.

| Column | Type | Description |
|---|---|---|
| `Decade` | string | Decade of first flight, e.g. `1990s`. |
| `CitizenGroup` | string | Citizenship group. |
| `Count` | int | Number of astronauts who first flew in that decade. |

## `data/processed/gender_by_year.csv`
New-astronaut counts by first-flight year × gender.

| Column | Type | Description |
|---|---|---|
| `FirstMissionYear` | int | Year of first spaceflight. |
| `Gender` | string | Male / Female / Unknown. |
| `Count` | int | Number of astronauts. |

## `data/astronaut_summary_v1_2024.csv`
The **original** summary CSV from the first version of this project (data through
2024, with a leading unnamed index column). Retained unchanged for provenance and
reproducibility comparisons; superseded by `data/processed/astronaut_summary.csv`.

## `docs/data/astronaut_data.json`
A single bundle combining all of the above plus pre-sorted duration arrays for
the box-and-whisker charts. Consumed directly by the dashboard (`docs/index.html`).
Regenerated by `build_dataset.py`; not intended to be edited by hand.
